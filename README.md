# BRUNAK — Architecture contemporaine & bioclimatique

> **Site immersif d'exception développé en React & Vite pour BRUNAK**, cabinet d’architecture contemporaine et bioclimatique basé à Abomey-Calavi au Bénin.

---

## 🏛️ Vision & Identité

BRUNAK façonne des espaces épurés et durables adaptés aux spécificités climatiques d'Afrique de l'Ouest :
- **Climat** : ventilation traversante, protection solaire naturelle et confort thermique passif.
- **Matière** : béton brut texturé, essences de bois nobles, pierres et terres locales.
- **Épure** : géométries franches, cadrages panoramiques et omniprésence de la lumière naturelle.

---

## ✨ Fonctionnalités immersives

- **Moteur immersif React + Lerp Scroll** : défilement cinétique ultra-fluide avec interpolation inertielle.
- **Scènes scrubées & épinglées** :
  - **Hero monumental** : dispersion dynamique d'un nuage de 10 photographies architecturales haute résolution.
  - **Manifeste dynamique** : encrage au défilement mot à mot avec tracé manuscrit vectoriel SVG.
  - **Sélection Projets (Masonry)** : grille interactive avec parallaxes multi-colonnes asymétriques.
  - **Devise en train de mots** : typographie cinétique horizontale (« Climat, Matière, Épure »).
  - **Processus & Méthode** : intro percutante *« Une vision, 3 jalons. »*, zoom cinématique, volet de transition et odomètre monumental.
  - **3 Témoignages clients** : navigation par onglets interactifs tactiles (`01`, `02`, `03`) et flèches de permutation.
  - **Objections & Traînée photographique** : traînée fluide de visuels suivant le curseur souris.
- **Menu Hamburger Architectural** : tiroir plein écran avec micro-animations, liens vers les 5 sections clés, informations de contact et réseaux.
- **Design 100 % Responsive** : adaptation parfaite du mobile (390 px) à la tablette (768 px) et grand écran (4K).
- **Favicon Monogramme vectoriel** : logo architectural SVG sur-mesure.
- **Crédit de conception** : `Craft by JoDev` avec lien direct vers [jovisleprinceyayi.com](https://jovisleprinceyayi.com).

## 🚀 Démarrage rapide

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure)
- npm ou pnpm

### Installation

```bash
# Cloner le dépôt
git clone <URL_DU_REPO>
cd "site immersif 2"

# Installer les dépendances
npm install

# Lancer en environnement local de développement
npm run dev
```

L'application sera accessible sur [http://localhost:5173](http://localhost:5173).

### Construction pour production

```bash
npm run build
```

Les fichiers optimisés seront générés dans le dossier `dist/`.
